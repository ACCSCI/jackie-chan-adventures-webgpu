# 成龙历险记 · 护身符之战（WebGPU）

改编自动画《成龙历险记》的 3D 网页动作游戏。整个游戏打包成**一个 HTML 文件**，双击就能玩（推荐 Chrome / Edge；浏览器不支持 WebGPU 时会自动退回 WebGL2）。

## 玩法亮点
- 第一集 · 公鸡护身符（5 章）：古董店 → 唐人街 → 刀鲁 → 渔人码头 → 仓库决战
- 第二集 · 龙之护身符（3 章）：龙王庙之夜 → 赤影忍者 → 龙之力·瓦尔蒙（火球可蹲躲，完美格挡能反弹）
- 第三集 · 蛇之护身符（3 章）：午夜博物馆 → 蛇影忍者 → 隐身的阿周。隐身敌人只留下脚印灰尘和立体声脚步声，出手前闪烁并发出“嘶——”声；打中隐身者会现形硬直。可撞碎的展柜、霸王龙骨架展品
- 通关第三集：蛇符觉醒——完美闪避/完美格挡后隐身 2.5 秒，第一击伤害 ×1.8
- 分层打击音效：CC0 的 Kenney Impact Sounds + qubodup Punch，按轻重/材质/反击/击杀/霸体叠加样本与合成低频，击杀与反击有更长的停顿
- 练功房：木人桩、陪练、10 项挑战
- 三种拳法，各有特性：**龙形拳**伤害系数 1.44、减伤 15%，连击越多伤害越高 · **蛇形拳**打中偷体力、走跑更快 · **醉拳** 80% 自动闪避（出招中也能闪）
- 轻击 / 重击、拳腿切换、蹲姿、格挡 / 完美格挡、闪避 / 完美闪避、鲤鱼打挺、4 秒不掉血自动回血
- 武器分三类（棍类 / 刀剑类 / 短打类），每类 3 种器械套路；背包可带 1 把备用武器
- **十二生肖符文**：按 Tab 打开装备 / 背包，最多装 3 个，持续生效
- 返回主界面、重开本章、进入练功房或继续第二集不再刷新网页，保留全屏
- 全屏游戏 + 键盘锁定：拦截浏览器快捷键，按住 Esc 退出全屏

## 战斗控制更新
- 滚轮 / Caps / X 切换拳腿，1 / 2 / 3 切换套路。右下角只显示当前拳腿，龙蛇醉使用国画水墨图标。
- Space 可立即取消地面攻击和棍术蓄力，清除排队连招；落地前 150ms 内按跳跃会缓冲执行。受击、倒地、过场仍受状态限制。
- **棍法 v3**：握持点修正到拳心（之前锚在手腕），手套式手型加握拳包裹；握位可沿棍身滑动（待机约 35%、劈扫滑到棍尾、转棍滑到中段）。待机单手持棍斜贴小臂与后背，跑动拖棍，停下时手腕转半圈收棍。
- **刀剑动作 v2**（`src/blade.js`）：剑/武士刀/雨伞改为拳心握柄、刃从虎口一侧伸出；刃口自动朝向挥砍方向（手腕最多翻转 ±75°）；待机为剑指护身的持剑架势，跑动时刀尖拖后。三派招式全部程序化：龙形刀双手力劈、斜斩、回刀横抹、平伸转身龙卷刀；蛇形剑直刺、低刺、弓步穿心刺、五连万剑归宗；醉剑仰身斩、回眸斩（醉仙踢/醉剑旋风保留全身片段）。蹲姿低扫、撩天斩、空中劈斩、双手倒持流星坠剑。共用棍法的转腰下沉、脚部 IK、弧面光带、收招残影和镜头冲击。
- **扫堂腿**：改为单腿全蹲、扫腿贴地伸直勾脚、上身前俯双手探地，整圈旋转；躯干逐节对准绝对方向，不再叠加蹲姿片段的弯腰。
- 全身驱动：转腰、送胯、前倾、重心下沉、脚部 IK 与程序化踏步；轻击单手，重击 / 蓄力双手，左手沿棍身滑到可及的握位。
- 轻棍五连三派通用：斜劈 → 反手横扫 → 背后转棍 → 双手旋风 → 跳起下劈（裂地）。按住左键转「棍花」，挡下正面攻击并弹回火球。
- 右键按住蓄力 1–3 段（0.4s / 0.82s 升段），重棍按流派：龙形劈棍（砸地裂开、尘环、范围伤害），灵蛇戳棍（3/5/7 连刺），醉棍立棍（插棍撑起无敌、离棍扫踢）。Space / Alt 可取消蓄力。
- 弯曲：二维弹簧（棍身本地 x/y），由棍梢相对速度驱动；中段握持时两端反向弯成 S 形；木棍约 20cm、扫帚更软、铁棍约 5cm；命中 / 停住时抖动。只影响画面，命中仍按直棍扫掠判定。
- 残影三层（全部固定对象池）：弧面光带（最近 9 帧 Catmull-Rom 补帧、加性渐隐）、7 个加粗棍身残影（0.2s）、收尾招式 3 个人物残影；颜色按流派（龙金 / 蛇青绿 / 醉紫），重击与收尾用水墨黑金。
- 打击感：挥棍风声音调随棍梢速度变化，每招独立命中停顿，命中时 FOV 冲击并沿命中方向震屏。
- `npm run test:combat` 执行浏览器战斗回归。首次使用需 `npx playwright install chromium`；也可通过 `CH` 环境变量指定本机 Chrome / Edge 可执行文件。

## 配音、音乐与音效
- 全部 152 句固定角色台词 / 喊话已换为 VibeHub 官方 CLI 生成的 **MiMo HD 语音**，另外补齐 21 条古董损坏数量的动态台词分支，共 **173 条**；不是原版动画配音，不克隆真人音色。
- 使用官方预设音色搭配各角色的导演提示：成龙沉稳温暖、老爹沙哑幽默、小玉活泼明亮、刀鲁粗犷低沉、瓦尔蒙优雅傲慢。
- 5 首 VibeHub CLI / MiniMax music-3.0 纯音乐：主菜单、探索 / 练功房、普通战斗、Boss 战、龙王庙夜景。
- 8 类 VibeHub CLI / ElevenLabs 音效：挥拳、轻击、重击、格挡、金属碰撞、受击、火球发射、火球命中。
- 场景音乐自动切换并交叉淡入淡出；对白时压低背景音乐。音效提前解码，最多 12 路并发，短间隔去重；未解码时沿用程序化音效，不阻塞战斗。
- 设置中可分别关闭「角色配音」和「背景音乐」，仍支持载入自定义音乐。
- 音频源在本地生成，编码为 Opus 后全部内嵌进 HTML；最终文件约 17.8 MiB，无需运行时联网加载音频。首次点击或按键后才播放声音（浏览器限制）。
- `assets/audio/lines.json`、`design.json`、`manifest.json` 分别记录台词、音色 / 提示词、来源与原始素材校验值。仓库不包含登录凭证或原始 WAV；构建使用 `assets/audio/hd/*.part` 数据分片。

## 构建
```bash
npm install
npm run build        # 输出 dist/index.html，支持 Windows / macOS / Linux
```
需要 Node 18+ 与 Python 3。

| `src/p1.js` | 渲染器、场景、画质 / 动态分辨率 |

| `src/staff.js` | 棍术路径、单手携棍 / 双手发力、弯曲、残影与扫掠判定 |

| `src/p3.js` | 输入、玩家控制、命中与受击 |
| `src/p4.js` | 敌人 AI、波次、武器与护身符拾取 |
| `src/p45.js` | 程序化配乐 |
| `src/p46.js` `src/p47.js` | 剧情、NPC、码头 / 仓库 / 练功房、菜单 |
| `src/p48.js` | 背包 / 装备栏、全屏与键盘锁定 |
| `src/p49.js` | 第二集：龙王庙场景、新敌人、剧情 |
| `src/websfx.js` | CC0 打击音效数据（来源见 `assets/audio/web/CREDITS.md`） |
| `src/p51.js` | 分层打击音效系统 |
| `src/p52.js` | 第三集：博物馆场景、隐身机制、剧情、蛇符觉醒 |
| `src/p50.js` | HD 配音缓存、BGM 切换、对白压低音乐、音效预解码与并发控制 |
