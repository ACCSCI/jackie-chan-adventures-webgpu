# 成龙历险记 · 护身符之战（WebGPU）

改编自动画《成龙历险记》的 3D 网页动作游戏。整个游戏打包成**一个 HTML 文件**，双击就能玩（推荐 Chrome / Edge；浏览器不支持 WebGPU 时会自动退回 WebGL2）。

## 玩法亮点
- 第一集 · 公鸡护身符（5 章）：古董店 → 唐人街 → 刀鲁 → 渔人码头 → 仓库决战
- 第二集 · 龙之护身符（3 章）：龙王庙之夜 → 赤影忍者 → 龙之力·瓦龙（火球可蹲躲，完美格挡能反弹）
- 第三集 · 蛇之护身符（3 章）：午夜博物馆 → 蛇影忍者 → 隐身的阿周。隐身敌人只留下脚印灰尘和立体声脚步声，出手前闪烁并发出“嘶——”声；打中隐身者会现形硬直。可撞碎的展柜、霸王龙骨架展品
- 通关第三集：蛇符觉醒——完美闪避/完美格挡后隐身 2.5 秒，第一击伤害 ×1.8
- 第四集 · 鼠之护身符（6 章）：潜入第十三区 → 兵马俑 → 镇墓石狮 → 货运升降井 → 飞艇甲板 → T-13
  - 潜入：守卫视野锥与侦测值、脚步噪声、蹲下躲矮掩体、背后按 F 制伏、倒地同伴会被发现、无线电 2.5 秒内打断可阻止警报、摄像头 / 激光绊线 / 电闸 / 格栅，按住 E 破解控制台；结算给出「幽灵 / 暗影 / 强攻」评价
  - 统一地面预警：红色只能躲、琥珀色可格挡、青色风带蹲下抵抗、紫色抓取、扩散冲击环要跳；背后来袭有屏幕边缘箭头
  - 新敌人：会碎的兵马俑（霸体）、铜鼠群、镇墓石狮（引它撞柱子会晕）、无人机（完美格挡把光弹打回去）、小队包围与夹击
  - Boss T-13 会学习你的习惯（闪避方向、格挡、轻击连段、滞空、拉开距离），右侧面板实时显示；换打法它就会遗忘对策
- 通关第四集：鼠符觉醒——完美闪避/完美格挡召唤两只铜鼠帮你咬敌人
- 第五集 · 虎之护身符（3 章）：雪山栈道 → 雪峰寺 · 刀鲁 → 阴阳台 · 黑成龙
  - 雪山栈道：东侧是悬崖——在崖边把敌人打飞（重击、反击）或让山风把他们吹下去就是一击毙命；青色风带蹲下抓稳；红线落石会把路上的人（包括敌人）一起撞下山；敌人分三批从两头包抄
  - 刀鲁：琥珀色横扫可格挡、红色跺地 / 冲撞只能躲（引他撞石灯笼或钟亭柱子会晕）、紫色抓取只能闪；半血发怒召唤影武者，跺地加冲击环。引他站到钟底下按 E 拉断钟绳，大钟罩住他 4 秒，掀开后头昏眼花，伤害 ×1.8；钟 10 秒后可再用
  - 黑成龙：会记录并**镜像回放你最近的连招**（轻招琥珀可挡、重招红色要躲、扫腿冲击环要跳），会影步瞬移到你背后、会学你闪避；半血召唤影子。顶部「阴阳盘」：出手推向阳、格挡 / 完美格挡 / 完美闪避推向阴，指针在金框内伤害 ×1.25，偏离 ×0.8，严重失衡只剩 ×0.35 且他会回血
- 通关第五集：虎符觉醒——完美格挡/完美闪避后 4 秒内，每次命中都有影子追击（50% 伤害）
- 第六集 · 牛之护身符（3 章）：家具城开业 → 样板间 · 衣柜伏兵 → 装卸区 · 拉索
  - 环境打击：把敌人打到家具上更疼、打到沙发上会弹飞；按 E 推倒货架、拆冰箱门当盾牌（可挡红线投掷物）；损坏商品会记到“账单”上
  - 衣柜在晃就是有人要跳出来——冲过去按 E 把柜门踹回去；拉索（牛符）正面打不动，绕背或引他冲撞高货架
- 通关第六集：牛符觉醒——重击把敌人打成“保龄球”撞倒路上的其他敌人，撞上家具伤害翻倍
- 第七集 · 马与羊（3 章）：唐人街夜市 · 芬恩 → 灵界 · 守护肉身 → 梦魇 · 阿周
  - 芬恩有马符：绿色圈是治疗，用重击 / 反击 / 大伤害打断；红线马踏冲刺可能连踏两次
  - 灵界：灵魂被打出肉身，游魂扑向肉身吸取力量——优先打掉正在吸的（红光）
  - 梦魇阿周：瞬移、分身（打中假身会消散）、地上红圈是梦里的手；半血后巨眼睁开，它看你时按住格挡
- 通关第七集：马符觉醒（完美格挡 / 完美闪避回 6 血）、羊符觉醒（完美闪避留下灵魂残影，1 秒后爆炸）
- 第八集 · 猴与兔（3 章）：马戏团 · 猴符 → 货运站 · 横穿的列车 → 调车转盘 · 瓦龙
  - 金色长条是变身光线：被射中会变成小猴子 6 秒（伤害减半、不能拿武器）；团长也会把打手变成猴子
  - 货运站：信号灯变红、地上亮红条就是列车要来——离开那条轨道，把敌人打上轨道让列车撞飞他们
  - 兔符瓦龙极快：连环冲刺、兔子跳红圈、油瓶紫圈（油渍减速），半血狂暴带残影；完美闪避他的冲刺触发子弹时间
- 通关第八集：猴符觉醒（空中攻击 +50%）、兔符觉醒（完美闪避后 3 秒出招速度 +30%）
- 第九集 · 狗、猪与圣主（3 章，最终集）：旧墓园 · 不死之身 → 猪神殿 · 热光眼 → 天界祭坛 · 圣主
  - 不死者血空后倒地 3 秒再爬起来——趁倒地用攻击（重击更远）把它打进金色封印圈才算消灭；最后出现狗符不死犬
  - 猪神像平时刀枪不入：躲到柱子后面（柱子会被烧塌）、跳过光线或翻滚躲过旋转热光，过热时背后发红，伤害 ×1.6；狂暴后双光束
  - 圣主（程序化巨龙）飞在天上：喷火扇形后会低头喘气、俯冲撞地后会卡住，那时打它的头；火雨看红圈。66% 时十二枚护身符共鸣，全部符文效果同时生效；33% 狂怒
  - 圣主虚弱时进入 QTE：跟着老爹念「妖魔鬼怪快离开」，按提示键 W / A / S / D / J / K（触屏可点按钮），失败会让它恢复一点血再来一次
  - 封印圣主后回到古董店，滚动致谢字幕，然后显示全剧终结算
- 通关第九集：狗符觉醒（不死之身冷却减 30 秒、触发时震飞周围敌人）、猪符觉醒（热光眼连射两发）
- 倒地时按 **Space** 快速起身（鲤鱼打挺；倒地瞬间按下会缓冲）
- 分层打击音效：Mixkit 免费授权的高质量拳脚 / 刀剑命中声 + VibeHub（ElevenLabs）生成的棍击、格挡、倒地声作主层，CC0 的 Kenney Impact Sounds + qubodup Punch 作纹理层，再叠合成低频；腿法、反击暴击、完美格挡各有专门的样本，击杀与反击有更长的停顿
- 练功房：木人桩、陪练、10 项挑战
- 三种拳法，各有特性：**龙形拳**伤害系数 1.44、减伤 15%，连击越多伤害越高 · **蛇形拳**打中偷体力、走跑更快 · **醉拳** 80% 自动闪避（出招中也能闪）
- 轻击 / 重击、拳腿切换、蹲姿、格挡 / 完美格挡、闪避 / 完美闪避、鲤鱼打挺、4 秒不掉血自动回血
- 武器分三类（棍类 / 刀剑类 / 短打类），每类 3 种器械套路；背包可带 1 把备用武器
- **十二生肖符文**：按 Tab 打开装备 / 背包，按等级解锁符咒槽（最多 12 个），持续生效
- 返回主界面、重开本章、进入练功房或继续第二集不再刷新网页，保留全屏
- 全屏游戏 + 键盘锁定：拦截浏览器快捷键，按住 Esc 退出全屏
- 手机 / 平板触控：左半屏浮动摇杆、右半屏拖动视角、右下按键簇；默认开启操作辅助（出招自动吸附最近敌人、镜头跟随目标、格挡判定更宽、连按轻击自动接连招、Boss 战自动锁定）。网址加 `?touch` 强制开启，`?notouch` 关闭
- 发力喊声 / 受击闷哼：重击、收招、反击、空中下劈、蓄力满段时成龙会喊“啊打！”，敌人出手和受击按体型 / 身份发声，全局限流避免吵闹（设置中可关闭）

## 大地图与成长（v10）
- **四张可以自由探索的大地图**，把原来一个个封闭场景串成一段旅程：剧情里要换场景时，成龙会出现在大地图上当前场景的门口，跟着金色光柱 / 小地图 ★ 走到下一个场景门口再继续剧情（嫌远可按 **T** 直接前往）。每集开头如果不在古董店，也会先从古董店门口出发。
  - **龙城湾区**（第一~三、六~九集）：唐人街牌楼与骑楼街、九层宝塔、横跨海湾的红色悬索大桥、集装箱码头巨型吊机、海湾摩天轮、南山电视塔、东边的摩天楼群和海湾小岛灯塔；古董店、唐人街广场、码头、仓库、龙王庙、博物馆、家具城、夜市、马戏团、火车站、墓园都有对应的门。
  - **内华达沙漠**（第四集）：红岩台地与石柱、天然石拱、胡佛大坝与高处水库、射电天线阵、66 号公路旅馆，尽头是第十三号基地。
  - **喜马拉雅**（第五集）：悬在深渊上的雪地平台、万丈深渊吊桥、整面山崖雕成的摩崖大佛、冰瀑、一千级天梯通往阴阳台，远处是上千米高的雪峰。
  - **天界仙山**（第九集）：云海上的浮岛和云桥、比山还高的南天门、环绕仙山缓缓转动的十二生肖神石、仙鹤和飞瀑。
- 大地图里有昼夜（按目的地场景决定）、路人、巡逻的打手（靠近或被打才会醒，整队一起上）、宝箱、地标（发现地标 +25 经验）；在大地图被打倒不会结束游戏，会在路边醒来。
- **支线任务**（头顶「!」的 NPC，靠近按 **E** 对话）：包子铺的麻烦（打跑打手）、失落的古董（收集 5 件）、号外！号外！（40 秒送报）、拳馆踢馆（单挑）、天外来石、走失的牦牛铃、武僧的考验、天灯。支线对白全部配音。
- **等级与符咒槽**：默认 0 级，打怪、支线、宝箱、地标、通关章节都给经验；每升一级解锁 1 个符咒槽，最多 12 级 / 12 槽（老存档至少 3 级）。升级回满生命与体力。
- **新背包**（Tab）：左边是 12 个符咒槽围成的圆形轮盘（未解锁的槽显示所需等级，中间是等级与经验），右上是武器栏（手中 / 背包），右下是物品栏（符咒和道具，点击装上 / 使用，可拖到左边的槽）。
- **道具**：叉烧包（回血，**V** 快速吃）、菊花茶（一段时间体力消耗减半）、跌打酒、武学残卷（+经验）、古董。
- 其他修复：倒地后 **Alt 和 Space** 都能鲤鱼打挺；蛇棍重击蓄力时右手不再跑到背后；古董店过场小玉不再卡进柜子、说话时不可见会被放到成龙身边；靠墙时镜头沿射线收回并在过近时抬高俯视；修复第九集的神殿函数覆盖了第二集龙王庙、导致第二集进错场景的问题。
- 反派「瓦尔蒙」统一改名为**瓦龙**，含名字的 11 句台词已用原音色重新配音。

## 地图、古董店与任务标记（v11）
- **M 打开全屏地图**（音乐开关改到 **N**；触屏左上角有「地图」按钮）：显示当前大地图的可走区域、建筑、各场景入口、地标（未发现的显示「？」）、支线 NPC 与任务目标、旅行目的地 ★ 和你的位置；在封闭场景里打开会显示所属大地图并标出「你在这里」。滚轮 / ＋－ 缩放、拖动平移，左键放置自定义标记（点标记删除、右键清除），标记会同步到小地图（紫点）、目标栏（距离）和 3D 紫色光柱，走到 4 米内自动清除。
- **任务目标标记**：接了支线后，每个目标（要送达的地点、待收集的物品、要打的敌人、回去交任务的 NPC）都会立起青色光柱，目标栏显示最近目标的距离，小地图同步标点；收集进度会存档。
- **古董店随时进出**：在龙城湾区走到「老爹古董店」门口就能进去（旅行目的地不变，店里按 T 也能直接前往）；走到老爹面前按 **E** 把古董交给他，每件 +60 经验，每累计 3 件送一卷武学残卷（台词已配音）。部分宝箱里也藏着古董。
- **看得见的边界**：所有大地图的可走区域边缘自动立起与场景风格一致的栏杆，取代看不见的空气墙；沙漠地面与可走区域对齐、山坡往外退，喜马拉雅补上村口到雪山栈道的雪道；补齐家具城、马戏团帐篷、火车站拱棚、吊机支腿、红岩拱门等建筑的碰撞，天门神殿后移不再挡住入口。
- 码头新增可见的「码头报亭」（支线「号外！号外！」的终点）。

## 战斗控制更新
- 滚轮 / Caps / X 切换拳腿，1 / 2 / 3 切换套路。右下角只显示当前拳腿，龙蛇醉使用国画水墨图标。
- Space 可立即取消地面攻击和棍术蓄力，清除排队连招；落地前 150ms 内按跳跃会缓冲执行。受击、倒地、过场仍受状态限制。
- **棍法 v3**：握持点修正到拳心（之前锚在手腕），手套式手型加握拳包裹；握位可沿棍身滑动（待机约 35%、劈扫滑到棍尾、转棍滑到中段）。待机单手持棍斜贴小臂与后背，跑动拖棍，停下时手腕转半圈收棍。
- **刀剑动作 v2**（`src/blade.js`）：剑/武士刀/雨伞改为拳心握柄、刃从虎口一侧伸出；刃口自动朝向挥砍方向（手腕最多翻转 ±75°）；待机为剑指护身的持剑架势，跑动时刀尖拖后。三派招式全部程序化：龙形刀双手力劈、斜斩、回刀横抹、平伸转身龙卷刀；蛇形剑直刺、低刺、弓步穿心刺、五连万剑归宗；醉剑仰身斩、回眸斩（醉仙踢/醉剑旋风保留全身片段）。蹲姿低扫、撩天斩、空中劈斩、双手倒持流星坠剑。共用棍法的转腰下沉、脚部 IK、弧面光带、收招残影和镜头冲击。
- **扫堂腿**：改为单腿全蹲、扫腿贴地伸直勾脚、上身前俯双手探地，整圈旋转；躯干逐节对准绝对方向，不再叠加蹲姿片段的弯腰。
- 全身驱动：转腰、送胯、前倾、重心下沉、脚部 IK 与程序化踏步；轻击单手，重击 / 蓄力双手，左手沿棍身滑到可及的握位。
- 轻棍五连三派通用：斜劈 → 反手横扫 → 背后转棍 → 双手旋风 → 跳起下劈（裂地）。按住左键转「棍花」，挡下正面攻击并弹回火球。
- 右键按住蓄力 1–3 段（0.4s / 0.82s 升段），重棍按流派：龙形劈棍（砸地裂开、尘环、范围伤害），灵蛇戳棍（3/5/7 连刺），醉棍立棍（插棍撑起无敌、离棍扫踢）。Space / Alt 可取消蓄力。
- 弯曲：二维弹簧（棍身本地 x/y），由棍梢相对速度驱动；中段握持时两端反向弯成 S 形；木棍约 20cm、扫帚更软、铁棍约 5cm；命中 / 停住时抖动。只影响画面，命中仍按直棍扫掠判定。
- 残影三层（全部固定对象池）：弧面光带（最近 9 帧 Catmull-Rom 补帧、加性渐隐）、7 个加粗棍身残影（0.2s）、收尾招式 3 个人物残影；颜色按流派（龙金 / 蛇青绿 / 醉紫），重击与收尾用水墨黑金。
- 打击感：挥棍风声音调随棍梢速度变化，每招独立命中停顿，命中时 FOV 冲击并沿命中方向震屏。
- `npm run test:combat` 执行浏览器战斗回归。首次使用需 `npx playwright install chromium`；也可通过 `CH` 环境变量指定本机 Chrome / Edge 可执行文件。
